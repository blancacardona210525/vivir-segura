# Vivir Segura — versión para GitHub Pages

Esta versión es únicamente de demostración y orientación.

## Archivos que deben estar en la raíz del repositorio
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js

No requiere Python ni backend.

## Importante
El formulario de pre-denuncia no envía ni almacena datos. Para convertirlo en un sistema institucional real se necesita un backend seguro y una integración oficial con las instituciones receptoras.
